# 開発者向け引き継ぎドキュメント

本ドキュメントは、「SPEC-IR レーザーガンバトルアリーナシステム」のプロジェクトへ新しく参加する開発者が、最短で全体像を把握するためのコンパクトな技術資料です。

## 1. プロジェクト概要
赤外線レーザー銃を用いたサバイバルゲームを、Webシステム上で管理するダッシュボードアプリです。
プレイヤーが操作する「スマホ（ゲーム画面）」が実機デバイスとBluetooth通信を行い、ゲームマスターが使う「管理画面（Admin）」が全体の開始/終了を管理します。

## 2. 技術スタック
- **フロントエンド**: HTML5, Vanilla CSS3, Vanilla JS
  - **重要**: レガシーブラウザ対応不要。ES Modules (`import`/`export`) でJSを分割構成しています。
  - Web Bluetooth APIを利用しているため、**Chromeブラウザ必須**かつ**HTTPS環境必須（ローカルはlocalhostのみ許可）**です。
- **バックエンド**: PHP (Ver 8推奨)
- **データベース**: MySQL / MariaDB (PDO利用)

## 3. システム構成 (アーキテクチャ)
本システムは**Server-Authoritative（サーバー権威型）モデル**です。
- クライアント（スマホ）のJS内では「現在の自身のHP」を決して自己管理せず、すべてサーバーからのレスポンスを正とします。
- クライアントは2秒に1回のHTTPポーリング（`get_players.php`, `get_match.php`）にて画面を最新状態に上書きします。
- これにより、野外での通信切断が数秒発生しても、再接続時に自動で状態が復旧します。

## 4. ディレクトリ構成
```text
/battle_arena/
├── api/          # データベースと接続し、JSONを返すPHPファイル群
├── admin/        # ゲームマスター用SPA。cssとjsはそれぞれサブフォルダ内
├── game/         # プレイヤー用SPA（game.phpのみで画面遷移なし）
│   └── js/       # アプリケーションロジック。細かくモジュール分割されている
├── assets/       # ゲームとAdminで共通利用するCSS、画像などのリソース。
│   └── video/    # DOWN時に再生される down.mp4 を格納
├── config/       # データベース接続設定 (db.php)
└── docs/         # その他詳細仕様書 (DATABASE.md等の公式ドキュメント)
```

## 5. 主要ファイルと役割
- **`game/game.php`**: プレイヤー用UIの骨組み。このファイル内でCSSの切り替えによって画面が遷移するSPA。
- **`game/js/linkon-main.js`**: 全体のJS処理のディスパッチャー。各モジュールを呼び出す。
- **`game/js/core/server-sync.js`**: サーバーとのポーリング通信・タイマー同期・ダメージのキューイング（リトライ処理）を一手に引き受ける最重要ファイル。
- **`api/apply_damage.php`**: 送信されたダメージに基づき、サーバー側で部位HP減少処理やダウン判定（ルールの適用）を行う。
- **`schema.sql`**: ローカル環境で一発構築するためのDB定義と初期データ。

## 6. 実装済み機能
- Bluetooth機器（銃・防具）の接続・切断・再接続およびUI上の警告表示
- 5種のダウン判定ルール（コア、全部位など）のリアルタイム処理
- 通信エラーによるダメージ多重送信の防御機能（UUIDによる重複排除）
- 試合のタイマー管理（切断時は自動で一時停止し、タイマーが正確にストップ＆レジューム）
- 試合開始からゲーム終了後リザルト画面表示までの完全なワンウェイループ

## 7. 未実装機能

## 8. 現在の課題・制約
- ポーリングによる2秒のディレイが発生するため、「撃たれてからスマホのHPが減るまで最大2秒」かかります。これは通信切断への堅牢性を優先した仕様ですが、よりリアルタイム性を求める場合はポーリング間隔の調整が必要です。
