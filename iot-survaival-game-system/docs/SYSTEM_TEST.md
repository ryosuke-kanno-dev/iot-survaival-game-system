# SPEC-IR レーザーガンバトルアリーナ 総合システムテスト仕様書

本書は、システムの全機能が正常に動作し、予期せぬ切断や操作に対して堅牢に設計されているかを確認するための網羅的なテスト項目です。

---

## 【1】Bluetooth接続・切断テスト（耐障害性テスト）

- [ ] **1-1. 初回接続**
  - 銃とアーマーの両方を接続し、画面が「CONNECTING」から「READY」へ遷移するか。
  - Admin画面で対象プレイヤーの表示が「✅ READY」に変わるか。
- [ ] **1-2. プレイ中の意図的切断**
  - PLAYING状態で、銃またはアーマーの電源を切る。
  - 瞬時に赤い警告オーバーレイ（「Bluetooth Device Disconnected」等）が画面全体を覆うか。
  - 警告表示中、UI上のボタンや射撃操作が一切機能しなくなるか（誤操作防止）。
- [ ] **1-3. 切断からの再接続復帰**
  - 1-2の警告画面のまま、デバイスの電源を入れ直し「手動で再接続する」ボタンを押す。
  - 再接続に成功し、警告画面が消えてPLAYING状態に復帰するか。
  - 復帰後、通信エラー等の異常がなくダメージ送受信が正常に行えるか。

---

## 【2】試合設定・Admin管理機能テスト

- [ ] **2-1. 試合時間とルールの一括更新**
  - 試合前(WAITING)に、Admin画面の「試合設定」から【試合時間: 5分】【ルール: 全部が0でDOWN】等に変更し「設定を変更」ボタンを押す。
  - 確認ダイアログで「OK」を押し、設定が保存されるか。
  - スマホ側から「START GAME」などを押す、またはAdmin画面でスーパーリロードしても、設定した【5分】とルールが維持されているか（勝手に初期値に戻らないか）。
- [ ] **2-2. 試合中の設定変更ブロック**
  - PLAYING中にAdmin画面で設定変更を試みた際、「試合中は設定を変更できません」とエラー表示され、ブロックされるか。

---

## 【3】ゲーム進行・トランジションテスト

- [ ] **3-1. 試合開始の同期**
  - 両プレイヤーがREADYの状態で、Admin画面から「🎯 試合開始」を押す。
  - 両プレイヤーのスマホ画面が同時に「PLAYING」（バトル画面）に切り替わり、設定した試合時間のカウントダウンが開始されるか。
- [ ] **3-2. Adminからの強制終了**
  - PLAYING中に、Admin画面から「🛑 試合強制終了」を押す。
  - 即座に全員のスマホ画面が「FINISH」や戦績画面（END）へ切り替わり、射撃音が止まるか。

---

## 【4】ダメージ判定とHP同期テスト（サーバー権威）

- [ ] **4-1. 基本被弾ログと合計HP**
  - ゲーム開始後、赤外線を受信（被弾）する。
  - 対象の「部位HP」が正しく減り、同時に上部の「合計HP（例: 580/600）」が同期して即座に減るか。
  - UI画面左下の「通信ログ」に「[HEAD]に20ダメージ」などが正しく表示されるか。
- [ ] **4-2. オフライン再送（キューイング）のテスト**
  - PLAYING中、あえてスマホのWi-Fi/4Gを数秒間切り離す（擬似的な機内モード等）。
  - その間に数発被弾させる（画面表示はエラーではなく待機状態になる）。
  - 3秒〜5秒後に通信を復帰させる。
  - キューに溜まっていたダメージデータがサーバーに自動再送され、遅れてHPがガクッと減るか（通信エラーでロスト落ちしないか）。

---

## 【5】各種ダウン(DOWN)状態のテスト

事前にAdmin画面でダウンルールを変更してから試合を開始し、以下の挙動を確認する。

- [ ] **5-1. TOTAL_HP_ZERO (合計HP=0)**
  - 合計HPが0になった瞬間に、画面全体が赤黒くなり「DOWN」の文字が表示されるか。
- [ ] **5-2. CORE_PART_ZERO (頭部または胴体=0)**
  - 合計HPが残っていても、頭部または胴体のHPを0にした時点で即座に「DOWN」判定になるか。
- [ ] **5-3. ANY_PART_ZERO (いずれかの部位=0)**
  - 腕や脚など、どこか一つでもHPが0になった瞬間にDOWNするか。
- [ ] **5-4. DOWN時の動作ブロック**
  - DOWN画面中、射撃や弾薬リロードの操作が完全にUI上で無効化（ポインター操作ブロック）されているか。
  - DOWNしているプレイヤーに対して、さらに追撃ダメージを与えた場合、エラーにならず（無視されて）処理が進むか。

---

## 【6】Adminの個別プレイヤー操作機能

- [ ] **6-1. 強制ダウン**
  - PLAYING中、生存しているプレイヤーのAdminパネル内「強制ダウン」ボタンを押す。
  - 対象プレイヤーのスマホ画面が即座にDOWN画面に強制遷移されるか。
- [ ] **6-2. HP全回復（蘇生）**
  - 上記でDOWNしたプレイヤーに対して、Adminパネルの「HP全回復」を押す。
  - 対象プレイヤーの全身のHPが100に、合計HPが600に戻るか。
  - DOWN画面が解除され、再びPLAYING画面（生存状態）に戻るか。

---

## 【7】タイムオーバーとリマッチ（再試合）テスト

- [ ] **7-1. 時間切れ終了**
  - 試合時間が0:00になった瞬間に、自動的に試合が終了し、リザルト画面（END画面）へ遷移するか。
- [ ] **7-2. 自動待機状態への復帰（リマッチ）**
  - リザルト画面で「戻る」ボタン、またはAdminの「🔄 リセット(次の試合へ)」を押す。
  - プレイヤー側は一瞬「初期状態（IDLE）」に戻った後、Bluetoothが繋がっていれば自動で再度「READY」画面に復帰するか。
  - このとき「不正な状態遷移: IDLE → PLAYING」などのエラーを吐かずに、直後の次の試合を無事開始できるか。

---

> **💡 テスト手順上のアドバイス**
> 
> * 本テストは、PC上のブラウザの開発者ツール（`F12` キー > 💻`Console` タブ）を開きながら行うことを強く推奨します。赤字のエラーログが出た場合はすぐに内容を控えられるようにしてください。
> * 万が一サーバーとスマホの表示にズレが生じた場合は、Admin画面の「🔄 全データ更新」を押すか、スマホ側のブラウザを完全にリロードして復帰できるか確認してください。
