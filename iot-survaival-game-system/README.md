# SPEC-IR Battle Arena System 🔫

SPEC-IR は、Bluetooth通信が可能な赤外線レーザー銃および防具デバイスを取り入れた、サバイバルゲームの「デジタル化管理システム」です。
プレイヤーが持つスマートフォンが実機端末と接続し、リアルタイムでHP（体力）や弾薬情報をサーバーと同期。ゲームマスターの管理画面から複数人の対戦をコントロールします。

## 🎯 主な機能
- **デバイス間同期**: Web Bluetooth APIによるスマートフォンと専用デバイス（銃・防具）の接続。
- **リアルタイム部位HP管理**: 頭部や胴体など、部位ごとのHPをサーバー権威モデルによって管理。
- **カスタムダウンルール**: 「合計HPが0」「頭・胴体が0になったら」など、5種類のダウン仕様をカスタマイズ可能。
- **堅牢な通信設計**: 野外での通信を前提とし、パケットロスによる「ダメージの二重適用」や「一時的な切断」からの即座の復旧に対応。
- **管理者ダッシュボード**: ホストが試合の時間設定、開始・停止、プレイヤーの強制ダウン操作などを一括して行えます。

## 🛠 技術スタック
- **Frontend**: HTML5, Vanilla CSS3, Vanilla JS (ES Modules)
- **Backend**: PHP 8+
- **Database**: MySQL / MariaDB (PDO)

## 🚀 セットアップ方法 (ローカル環境構築)

本プロジェクトは外部ライブラリのビルド環境などを必要としないため、簡単に立ち上げることができます。

### 1. 必須環境の準備
- [XAMPP](https://www.apachefriends.org/jp/index.html) または任意のPHP/MySQL動作環境。
- Chrome等の「Web Bluetooth API」に対応した最新ブラウザ。

### 2. インストール手順
1. 本リポジトリをZIPダウンロート、または `git clone` して、XAMPPの `htdocs` 配下にフォルダを配置します。（フォルダ名は `battle_arena` を推奨）
2. XAMPPのコントロールパネルから、**Apache** と **MySQL** を起動します。
3. ブラウザで `http://localhost/phpmyadmin/` へアクセスします。
4. `schema.sql` の中身をコピーし、phpMyAdminの「SQL」タブに貼り付けて実行します。
   - これで `battle_arena` データベースが作成され、初期のプレイヤーデータ（Player 1, 2）が流し込まれます。

### 3. 初期設定
`config/db.php` を開き、必要に応じてMySQLの接続パスワードを変更してください（デフォルトは `root` / パスワードなし です）。

```php
$user = 'root';
$pass = '';
```

## 🎮 使用方法

システムは大きく分けて「管理用画面」と「プレイヤー用画面」に分かれています。

### 管理画面 (Admin)
- **URL**: `http://localhost/battle_arena/admin/admin.php`
- ゲームマスターはここから試合時間を設定し、「試合開始」ボタンでタイマーを開始します。
- 接続断線等のエラーもこの画面にポップアップ表示されます。

### プレイヤー画面 (Game)
- **URL**: 
  - Player 1: `http://localhost/battle_arena/game/game.php?player_id=1`
  - Player 2: `http://localhost/battle_arena/game/game.php?player_id=2`
- スマホ（またはPCブラウザ）で各プレイヤーのURLを開きます。
- 画面中央の「Bluetooth接続」ボタンをタップし、手元の銃・防具デバイスとペアリングを行ってください。接続に成功すると緑色のチェックマークが入ります。
- 参加者全員の準備が完了した後、Adminが試合を開始すると画面のタイマーが動き出し、ゲームが進行します。

*※Web Bluetooth APIを使用するため、スマホの実機テストを行う場合は ngrok 等を用いてHTTPS化したURLを利用する必要があります。*

## 📁 ディレクトリ構成

```text
/battle_arena/
├── api/          # データベースと接続し、JSONを返すPHPエンドポイント群
├── admin/        # ゲームマスター用SPA画面とロジック（Admin）
├── game/         # プレイヤー用SPA画面とロジック（UIとハードウェアの仲介）
├── assets/       # ゲームとAdminで共通利用するCSS、画像、動画等のリソース
└── docs/         # API設計や各システムのフロー等の公式仕様書
```
